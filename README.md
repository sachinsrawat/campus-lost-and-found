# Campus Lost & Found 🔎

A responsive web application that helps college students report lost belongings, list found items, and search for missing items on campus through a simple, user-friendly interface.

## 🌐 Live Demo

https://sachinsrawat.github.io/campus-lost-and-found/

## ✨ Features

- **Report Lost Items:** Add details about belongings that have gone missing.
- **Report Found Items:** Post information about items found on campus.
- **Search Items:** Find listings using keywords.
- **Category Filtering:** Browse items by category.
- **Item Details:** View descriptions and relevant information about listed items.
- **Responsive Design:** Works across desktop, tablet, and mobile screens.
- **Local Storage:** Retain listings in the browser between visits.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage API

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/sachinsrawat/campus-lost-and-found.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Start reporting and browsing lost-and-found items.

## 🎯 Project Purpose

Campus Lost & Found aims to make it easier for students to reconnect with lost belongings by providing a centralized, accessible platform for sharing lost-and-found information.

The project demonstrates practical front-end development skills, including DOM manipulation, event handling, responsive UI design, form validation, and browser-based data persistence.
